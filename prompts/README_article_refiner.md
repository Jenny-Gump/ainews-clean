# Article Refiner Prompt

## Назначение
Промпт `article_refiner.txt` используется для второго этапа обработки текста после первичного перевода. Он улучшает качество русского текста, исправляя англицизмы и неестественные конструкции.

## Когда применяется
- **Phase 4**: WordPress Preparation
- **После**: Первого DeepSeek Reasoner (article_translator.txt)
- **Перед**: Генерацией тегов (tag_generator.txt)

## Что делает
1. Принимает уже переведенный русский текст в HTML формате
2. Исправляет англицизмы и кальки с английского
3. Улучшает естественность русской речи
4. Сохраняет все HTML теги и структуру
5. НЕ трогает метки изображений [IMAGE_N]
6. НЕ переводит названия брендов, продуктов, технологий

## Входные данные
- `{title}` - заголовок статьи на русском
- `{content}` - HTML контент на русском (результат первого Reasoner)
- `{excerpt}` - краткое описание
- `{slug}` - URL slug
- `{categories}` - категории (JSON array)
- `{_yoast_wpseo_title}` - SEO заголовок
- `{_yoast_wpseo_metadesc}` - SEO описание
- `{image_caption}` - подпись к изображению
- `{focus_keyword}` - ключевое слово

## Выходные данные
JSON объект с теми же полями, но с улучшенным полем `content`.

## Примеры исправлений
- "heavily rely" → "сильно зависят"
- "adequately capture" → "адекватно отражать"
- "demonstrated превосходство" → "продемонстрировали превосходство"
- "extensive исследования" → "обширные исследования"

## Конфигурация
В `core/config.py`:
```python
enable_second_reasoner = True  # Включить/выключить
second_reasoner_model = 'deepseek-reasoner'  # Модель
second_reasoner_timeout = 90  # Таймаут в секундах
```

## Обработка ошибок
Если второй Reasoner падает или возвращает невалидный ответ, система использует результат первого Reasoner.

## Логирование
Все операции логируются в `logs/operations.jsonl` с фазой `wordpress_prep_v2`.
