## [1.1.0] - 2025-08-12

### 🔒 Критические исправления безопасности

#### Исправленные уязвимости (КРИТИЧНО)
- **AJAX безопасность**: Исправлены множественные уязвимости в AJAX обработчиках
- **Санитизация данных**: Добавлена полная санитизация всех пользовательских вводов
- **Nonce проверки**: Реализована правильная проверка nonce на всех формах и AJAX запросах
- **Валидация файлов**: Добавлена проверка типа и размера файлов для импорта/экспорта
- **Ограничение запросов**: Реализовано ограничение частоты запросов (защита от DoS)
- **Белый список настроек**: Добавлен белый список для предотвращения неавторизованных обновлений
- **Экранирование вывода**: Улучшено экранирование для предотвращения XSS атак
- **SQL инъекции**: Добавлены меры защиты от SQL инъекций с подготовленными запросами
- **CSRF защита**: Реализована защита от CSRF на всех операциях изменения состояния
- **Проверка прав**: Добавлены проверки прав доступа для всех админских функций

#### Новые функции безопасности
- Комплексный набор тестов безопасности (`tests/test-security.php`)
- Валидация настроек с проверкой типов и ограничениями
- Ограничение частоты для всех AJAX операций:
  - Сохранение настроек: 10 запросов/минута
  - Сброс настроек: 3 запроса/час
  - Очистка кэша: 5 запросов/час
  - Оптимизация БД: 1 запрос/час
  - Импорт/Экспорт: 5-10 запросов/час
- Валидация загружаемых файлов:
  - Проверка типа файла (только JSON)
  - Проверка MIME типа
  - Ограничение размера файла (максимум 1MB)
  - Валидация структуры JSON
- Улучшенная безопасность JavaScript:
  - Улучшенное экранирование HTML
  - Валидация ввода на стороне клиента
  - Утилита форматирования размера файлов

#### Изменения в коде
- Все AJAX обработчики теперь требуют валидный nonce и проверку прав
- Настройки теперь проверяются по белому списку перед сохранением
- Функциональность импорта/экспорта полностью переписана с учетом безопасности
- Запросы к базе данных теперь используют исключительно подготовленные выражения
- Весь вывод теперь правильно экранируется в зависимости от контекста
- Сообщения об ошибках больше не раскрывают конфиденциальную информацию

### ⚠️ Важные замечания
- Этот выпуск устраняет все известные уязвимости безопасности
- Все исправления протестированы с помощью включенного набора тестов безопасности
- Рекомендуется очистить все кэши после обновления
- Проверьте права пользователей после обновления
- Временно включите режим отладки WordPress для отслеживания проблем
