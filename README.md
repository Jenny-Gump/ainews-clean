# AI News Parser - Single Pipeline + External Prompts System

🤖 **Автоматизированная система сбора и публикации новостей об ИИ с внешними промптами**

## 🎯 Описание

AI News Parser - это система с единым пайплайном для обработки новостей об искусственном интеллекте. Система работает по принципу **"1 запуск = 1 статья"**, обрабатывая каждую статью через все фазы: от сбора до публикации в WordPress. 

**🆕 Новое**: Все промпты для LLM вынесены в отдельные файлы для легкого редактирования без изменения кода.

## ✨ Ключевые особенности

### 🔧 Архитектура
- **Единый пайплайн**: 1 запуск = 1 статья
- **5 фаз обработки**: RSS → Парсинг → Медиа → Перевод → Публикация
- **29 источников**: RSS и Google Alerts
- **Простая очередь FIFO**: без приоритетов
- **Обработка статей**: Single Pipeline или Continuous mode

### 🆕 Система внешних промптов
- **Файлы промптов**: `prompts/` - легкое редактирование без кода
- **4 промпта**: очистка контента, перевод, теги, метаданные изображений
- **Динамическая подстановка**: переменных в промпты

### 🤖 ИИ-интеграция
- **Firecrawl Scrape API**: сохранение структуры и ссылок
- **DeepSeek AI**: умная очистка контента и перевод
- **OpenAI GPT-3.5**: генерация тегов и обработка медиа
- **Fallback система**: GPT-4o и GPT-3.5 при недоступности DeepSeek

### 🏷️ Умная система тегов
- **74 кураторских тега**: модели ИИ, компании, персоны
- **Автоматическая генерация**: 2-5 релевантных тегов на статью
- **Создание новых**: автоматически для важных терминов
- **WordPress интеграция**: прямая публикация с тегами

### 🖼️ Обработка изображений
- **Реальные URL**: извлечение настоящих ссылок из контента
- **Плейсхолдеры**: [IMAGE_N] для правильного размещения
- **Русские alt-тексты**: автоматический перевод метаданных
- **Валидация**: размер, формат, доступность
- **🆕 Умная обработка ошибок**: медиа failure НЕ блокирует публикацию
- **🆕 Очистка плейсхолдеров**: failed картинки убираются из контента

### 🌐 WordPress интеграция
- **Сайт**: https://ailynx.ru
- **Custom plugin**: без ограничений SEO полей
- **19 категорий**: под родительской "Новости"
- **Yoast SEO**: полная интеграция с русскими метаданными

## 🆕 Система внешних промптов

### Обзор
Все промпты для LLM вынесены в отдельные файлы в папке `prompts/` для простого редактирования без изменения кода.

### Файлы промптов

#### 1. `content_cleaner.txt` - Очистка контента DeepSeek AI
- Извлекает чистый контент статьи из raw markdown
- Сохраняет **реальные URL изображений** (не создает примеры)
- Добавляет плейсхолдеры [IMAGE_N] в логических местах

#### 2. `article_translator.txt` - Перевод статей
- Переводит на русский с HTML форматированием
- Добавляет экспертный комментарий в `<blockquote>`
- Выбирает категории из разрешенного списка

#### 3. `tag_generator.txt` - Генерация тегов  
- Выбирает 2-5 релевантных тегов из 74 кураторских
- Создает новые теги только для важных AI-моделей/компаний
- Приоритизирует конкретные термины над общими

#### 4. `image_metadata.txt` - Метаданные изображений
- Переводит alt-текст изображений на русский
- Создает SEO-friendly слаги для файлов

### Использование

```python
from services.prompts_loader import load_prompt

# Загрузка промпта с переменными
prompt = load_prompt('content_cleaner', 
    url=article_url,
    content=raw_content
)
```

## 🚨 Устранение неисправностей

### Нет статей для обработки
```bash
python core/main.py --stats  # Проверить статистику
# Добавить тестовую статью (см. раздел Тестирование)
```

### Теги не появляются
- ✅ **ИСПРАВЛЕНО** - Причина: ошибка в `log_operation()`
- Теги теперь корректно генерируются и добавляются в WordPress
- Проверьте логи на наличие "Generated tags: [...]"

### Битые изображения  
- ✅ **ИСПРАВЛЕНО** - DeepSeek теперь извлекает реальные URL
- Обновлен промпт `content_cleaner.txt` с четкими инструкциями
- Больше никаких фальшивых "example.jpg" URL

### 🆕 Статьи застревают в статусе `parsed`
- ✅ **ИСПРАВЛЕНО** - Критический баг медиа обработки устранен
- **Причина была**: Если хоть одна картинка failed, WordPress phases не запускались
- **Исправление**: Медиа failure больше НЕ блокирует процесс обработки
- **Поведение**: Статьи публикуются даже если все картинки failed
- **Плейсхолдеры**: `[IMAGE_N]` автоматически убираются для несуществующих картинок

### Ошибки API
- Проверьте файл .env
- Убедитесь в корректности API ключей
- Соблюдайте паузы между запросами
- DeepSeek имеет fallback на GPT-4o для перевода
- Генерация тегов имеет fallback на GPT-3.5
