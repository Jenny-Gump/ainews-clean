## 🚀 Установка в WordPress:

### Способ 1: Через админку WordPress
1. Зайдите в **Плагины → Добавить новый**
2. Нажмите **Загрузить плагин**
3. Выберите файл `code-highlighter-copy.zip`
4. Нажмите **Установить**
5. После установки нажмите **Активировать**

### Способ 2: Через FTP
1. Распакуйте `code-highlighter-copy.zip`
2. Загрузите папку `code-highlighter-copy` в `/wp-content/plugins/`
3. Зайдите в админку WordPress
4. Перейдите в **Плагины**
5. Найдите **Code Highlighter with Copy Button** и активируйте
